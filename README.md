# WILD NATURE AI AUTOMATION

د وحشي ژوو او مرغانو د مستندونو د اتومات سیستم بنسټ.

## د لومړي پړاو موخه
- د BirdNET Taxonomy 0.4-Oct2026 د مرغانو معلومات ساتل.
- د CSV سرچینه SQLite ته واردول.
- د مستند لپاره د مارغانو لټون او ټاکنه اسانه کول.
- د ۳۰ دقیقو لومړني مستند لپاره د تولید تنظیمات ساتل.

## د معلوماتو سرچینه
`database/source/world_birds_only_database.csv`

دا فایل د BirdNET Taxonomy له اصلي فایل څخه د Aves ډلې ریکارډونه لري. د taxonomy سرچینه د نادروالي یا د ساتنې د خطر وروستۍ درجه نه ده؛ د هر ډول د خطر حالت، جغرافیه او چلند باید له باوري سرچینو جلا وکتل شي.

## نصب او اجرا
```bash
python -m pip install -r requirements.txt
python scripts/import_birdnet_csv.py
```
SQLite ډیټابېس به `database/world_birds.sqlite` کې جوړ شي.

## د پروژې لومړني اصول
- د مستند غږونه: یوازې طبیعي چاپېریالي غږونه.
- د وحشي ژوو صحنو کې انسانان نه ښکاري.
- د نوعې بڼه، استوګنځای، ځاله، هوا او رڼا د صحنو ترمنځ ثابت ساتل.
- لومړی مرجع انځورونه، بیا د هماغو انځورونو مطابق ویډیو کلیپونه.
- د حق‌الطبع او انځور د جواز معلومات باید وکتل شي.
